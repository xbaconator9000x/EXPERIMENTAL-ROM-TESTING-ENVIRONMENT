# Runtime efficiency, bounded recovery and measurement

When a validated single-battle dispatcher is active directly after a native
menu A/B input, the agent can wait for two native animation intervals instead
of paying for repeated vision inference. It never auto-confirms unknown
battle prompts. A known-field stall (four of five visual decisions at the
same native coordinates) can delegate an untried event to the exploration
engine. Observed map transitions are retained across intervening locked
frames; they describe observations, not proof of specific warp causality.
Remote guidance can contribute normal movement witnesses.

Metrics are accumulated only after a successful decision step: native policy
decisions, successful strategic model calls, their measured wall durations,
other decisions, and processed emulator frames. A native action that used
vision for admission counts in both native and model-call fields, so the
fields are not mutually exclusive. Timing excludes some checkpoint/report
overhead and is not a promise of measured overall speed. Metrics start at
installation; existing earlier counters stay intact. The dashboard and
private progress reports expose those measurements without uploading saves,
RAM dumps, ROM bytes or private source. Exact English runtime acceptance is
still required.
